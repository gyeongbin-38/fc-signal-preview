# 원본 자산 정책

이 패키지는 공식 카드 배경·선수 사진·신규특성 아이콘·폰트 파일을 임의로 재배포하지 않는다. 실제 공식 CDN URL 참조와 원본 DOM 수집/검수 도구를 제공한다. CDN에 공개되었다는 사실은 영리 재사용 허가가 아니다.

공식 카드 전체 캡처는 assets/official/<spid>_<grade>.png + manifest로 추가한다. 파일은 PNG로 재검사하고 SHA-256·정확한 카드/강화·표시조건을 검증한다. 검토가 끝나기 전 default로 사용하지 않는다. 저장소/배포에 원본이미지를 넣기 전 정책을 확인한다.

현재 official 디렉터리는 비어 있다. UI의 선수사진 주소는 문서화된 템플릿 후보이며 실제 바이너리/사진 선택은 미검증. 사진/배지 참조만 성공해도 배경과 강화 외형까지 일치했다고 주장하지 않는다. 원본이 없으면 가짜 카드 대신 중립 텍스트를 표시한다.
